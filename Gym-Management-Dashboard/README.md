# 🏋️ Gym Management Dashboard | Power BI

## 📌 Overview

An interactive Gym Management Dashboard built using **Power BI**, **DAX**, and **Excel**. The dashboard provides insights into gym operations, membership, attendance, trainer performance, and revenue.

## 🚀 Features

- 👥 Total Members
- 💰 Total Monthly Revenue
- 🔥 Active Members
- 📉 Cancellation Rate
- 📈 Average Visits per Member
- 💷 Average Revenue per Member
- 🏋️ Trainer Revenue Analysis
- 📅 Attendance Trends
- ⏰ Peak Gym Hours
- 🎯 Membership & Goal Analysis

---

## 🛠️ Tools Used

- Microsoft Power BI
- DAX
- Microsoft Excel
